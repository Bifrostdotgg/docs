The Tebex integration links your Tebex game store to Discord. Staff can look up transactions, issue gift cards, and process manual claims without leaving Discord. Members can check the status of their own purchases.

## Setup

Navigate to <DashboardLink to="tebex/config">**Tebex \> Configuration**</DashboardLink> in the dashboard and enter your Tebex API key. The key is found in your Tebex store's **Settings \> API Keys** section.

```text
/tebex
```

The base command provides access to all Tebex subcommands through an interactive panel.

## Transactions

```text
/tebex transaction lookup <transaction_id>
```

Looks up a specific transaction by its Tebex transaction ID. Returns:

- The package purchased
- The buyer's name and email
- Purchase date
- Payment amount and currency
- Current transaction status

Navigate to <DashboardLink to="tebex/transactions">**Tebex \> Transactions**</DashboardLink> in the dashboard to browse transactions, search by buyer, and filter by date range or package.

## Purchase history

```text
/tebex lookup <username>
```

Lists a player's 10 most recent purchases by their Tebex username, each with its transaction ID, amount, packages and date, plus their total number of purchases. This needs the store's **Game Server API secret**, set under **Tebex \> Configuration \> API Keys**.

## Gift cards

```text
/tebex giftcard list
/tebex giftcard lookup <id>
/tebex giftcard create <amount> [note]
/tebex giftcard topup <id> <amount>
/tebex giftcard void <id>
```

| Subcommand | Description |
| --- | --- |
| `list` | Lists your store's gift cards with their ID, code and balance |
| `lookup` | Shows one gift card's code, balance, status and note. It takes the gift card's numeric **ID**, not its code; `list` shows each card's ID |
| `create` | Generates a new gift card for the specified value in your store's currency |
| `topup` | Adds value to an existing gift card |
| `void` | Voids a gift card so it can no longer be used |

Gift card codes are generated through the Tebex API and can be distributed to members directly. Creating, topping up and voiding gift cards is part of Tebex store administration, which needs [Premium](/premium).

## Claims

Claims allow you to manually grant packages to members. Navigate to <DashboardLink to="tebex/claims">**Tebex \> Claims**</DashboardLink> in the dashboard or use the Tebex slash command to manage pending claims.

## Role Mappings

Role mappings automatically assign Discord roles when a member purchases a specific Tebex package. Navigate to <DashboardLink to="tebex/mappings">**Tebex \> Role Mappings**</DashboardLink> to configure them.

Each mapping defines:

| Setting | Description |
| --- | --- |
| **Package** | The Tebex package that triggers the mapping |
| **Role to grant** | The Discord role assigned on purchase |
| **Role to remove** | An optional Discord role removed on purchase (useful for upgrading membership tiers) |
| **Persistent** | Whether the role assignment is permanent or should be removed if the member's subscription lapses |

For subscription packages, Heimdall can optionally remove the role when the subscription expires or is cancelled. This requires your Tebex webhook to be configured to send subscription events.

## Required permissions

| Action | Permission key |
| --- | --- |
| Viewing store information | `tebex.store.view_store` |
| Managing store settings | `tebex.store.manage_store` |
| Viewing transaction history | `tebex.store.view_transactions` |
| Issuing gift cards and processing claims | `tebex.store.manage_claims` |
