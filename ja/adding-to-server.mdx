## 前提条件

Heimdallを追加したいDiscordサーバーで、**サーバー管理**（Manage Server）権限が必要です。

## Botを招待する

**[bot.bifrost.gg](https://bot.bifrost.gg)** にアクセスし、**Add to Server**（サーバーに追加）をクリックします。これはBifröstがホストしているHeimdallで、自分でホスティングする必要はありません。招待リンクは、Botに必要な権限をちょうどそのとおりに要求します。Discordが、あなたが管理しているサーバーの一覧からサーバーを選ぶよう求め、続いて要求された権限の確認を求めます。

<Note>
追加する前にHeimdallを検討している場合は、**[bifrost.gg/heimdall/pricing](https://bifrost.gg/heimdall/pricing)** で利用できるプランを確認してください。すべてのプランで使える機能もあれば、有料プランが必要な機能もあります。
</Note>

<Info>
Heimdallが参加した後で、権限を取り除くこともできます。Discordでは **サーバー設定 > ロール** や、チャンネルごとの権限の上書きで変更できます。ただし、取り消した権限が必要な機能は動かなくなります。メンバーが影響を受ける機能を使おうとすると、Heimdallは何も言わずに失敗するのではなく、どのDiscord権限が足りないのかを具体的に示すエラーメッセージで応答します。そのため、何かが動かなくなったときでも、足りない権限を簡単に特定して直せます。
</Info>

## 必要な権限

Heimdallがすべてのプラグインで正しく動くには、次のDiscord権限が必要です。

| 権限 | 必要な理由 |
|---|---|
| ロールの管理（Manage Roles） | ロールボタンでのロール付与と、Minecraftのロール同期 |
| チャンネルの管理（Manage Channels） | 一時ボイスチャンネルの作成と削除 |
| メンバーをキック（Kick Members） | モデレーションコマンドによるキックの実行 |
| メンバーをBAN（Ban Members） | BANの実行と、退出時BANの管理 |
| メッセージの管理（Manage Messages） | 一括削除でのメッセージの削除と、固定メッセージの管理 |
| メッセージ履歴を読む（Read Message History） | 件数指定でのメッセージの一括削除と、Modmailの文脈の読み取り |
| メッセージを送信（Send Messages） | コマンドへの応答と通知の送信 |
| 埋め込みリンク（Embed Links） | 整形されたすべての出力でのリッチな埋め込みの送信 |
| ファイルを添付（Attach Files） | チケットやModmailのスレッドでの添付ファイルの送信 |
| アプリコマンドを使う（Use Slash Commands） | スラッシュコマンドの登録と応答 |
| スレッドの管理（Manage Threads） | チケットやModmailのスレッドの作成とアーカイブ |
| メンバーをタイムアウト（Moderate Members） | ミュートの処分でのタイムアウトの適用 |

## Botが参加したときに起きること

Heimdallが初めてサーバーに参加すると、すべてのスラッシュコマンドをDiscordに登録し、データベースにサーバーの設定項目を作成します。チャンネルやロールが自動的に作成されることはありません。すべてダッシュボードで設定します。

## 次のステップ

<Steps>
  <Step title="ダッシュボードにログインする">
    **[bot.bifrost.gg](https://bot.bifrost.gg)** にアクセスし、Discordアカウントでサインインします。サーバー選択画面にあなたのサーバーが表示されます。使い方は [ダッシュボードの使い方](/ja/dashboard) を参照してください。
  </Step>
  <Step title="権限を設定する">
    デフォルトでは、すべてのモデレーションコマンドは管理者権限を持つメンバーに制限されています。権限システムを設定して、各機能に適切なロールがアクセスできるようにしましょう。[権限](/ja/permissions) を参照してください。
  </Step>
  <Step title="プラグインを有効にして設定する">
    各機能は、設定してはじめて有効になります。ダッシュボードのサイドバーから各プラグインの設定ページを開き、設定してください。
  </Step>
</Steps>
