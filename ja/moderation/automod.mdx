Automodでは、サーバー内のすべてのメッセージに対してBotが評価するルールを定義できます。メッセージがルールに一致すると、Botは設定に応じて、メッセージを削除したり、送信者に警告したり、ミュートしたり、それらを組み合わせたりできます。ルールはバックグラウンドで動き、スタッフが関わる必要はありません。

## ルールの仕組み

各ルールには、**トリガー**、**除外対象**、**対応** があります。トリガーは、ルールが探すパターンを決めます。除外対象は、ルールが無視するチャンネル、ロール、ユーザーを決めます。対応は、ルールが発動したときにBotが何をするかを決めます。

ルールは順番に評価されます。1つのメッセージが複数のルールに一致することもあり、その場合はそれぞれのルールが独立して対応を適用します。

## ルールを作成する

ダッシュボードの <DashboardLink to="moderation/rules">**Moderation \> Rules**</DashboardLink>（モデレーション > ルール）を開き、**New Rule**（新しいルール）をクリックします。

### トリガーの種類

| 種類 | 説明 |
| --- | --- |
| **Keyword**（キーワード） | 特定の単語やフレーズを含むメッセージに一致します。デフォルトでは大文字と小文字を区別しません。 |
| **Regex**（正規表現） | 正規表現のパターンでメッセージに一致させ、複雑なフィルタリングを行います。 |
| **Spam**（スパム） | 繰り返しのメッセージ、メンションスパム、メッセージの送信頻度の制限を検出します。 |
| **Link**（リンク） | 特定のドメインやURLパターンに一致するリンクをブロックします。 |
| **Attachment**（添付ファイル） | 特定のファイル形式、または添付ファイルそのものをブロックします。 |
| **Caps**（大文字） | 大文字の割合が高いメッセージを検出します。 |

### ルールの処分

| 処分 | 説明 |
| --- | --- |
| **Delete**（削除） | メッセージをすぐに削除します。 |
| **Warn**（警告） | ポイント数を設定できる警告の違反を記録します。 |
| **Mute**（ミュート） | 設定した期間のタイムアウトを適用します。 |
| **Kick**（キック） | メンバーをサーバーから追い出します。 |
| **Ban**（BAN） | メンバーをBANします。期間を指定することもできます。 |
| **Send response**（返信を送信） | 処分の理由を説明するメッセージを投稿します（DMにすることもできます）。 |

処分は組み合わせられます。よくある設定は削除 \+ 警告で、メッセージを削除し、メンバーの違反記録に警告を追加します。

### 除外対象

特定のロール、チャンネル、ユーザーをルールの対象から除外できます。たとえば、リンクフィルターでスタッフのロールを除外すれば、モデレーターは自由にリンクを投稿できます。

### ポイント数

ルールで警告の処分を行う場合、その違反に付けるポイント数を設定できます。このポイントは段階的処分のシステムに反映されます。しきい値の仕組みについては [段階的処分](/ja/moderation/escalation) を参照してください。

## ルールをテストする

ルールを作成したら、ルールエディターの下部にある **Test**（テスト）入力欄で、サンプルのメッセージが想定どおりに一致する（または一致しない）かを確認しましょう。テストではルールのロジックだけが実行され、実際に処分が行われることはありません。

## ルールの順番と優先度

ルールは上から下へ評価されます。リスト内のルールをドラッグして並べ替えられます。ルールごとに **Stop on match**（一致したら停止）オプションがあり、有効にすると、そのルールが発動した時点で、同じメッセージに対してそれ以降のルールは評価されません。

## 必要な権限

| 操作 | 権限キー |
| --- | --- |
| ルールの閲覧 | `moderation.config.view_config` |
| ルールの作成と編集 | `moderation.enforcement.manage_rules` |
