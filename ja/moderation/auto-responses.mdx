自動応答とは、設定したパターンに一致するメッセージをメンバーが送ったときに、Heimdallが投稿する自動の返信です。取り締まりや処分を行うautomodのルールとは違い、自動応答は返信するだけで、情報を伝えるためのものです。よくある使い方は、よくある質問への回答、メンバーを適切なチャンネルへ案内すること、キーワードに反応して役に立つリソースのリンクを返すことなどです。

## 自動応答の仕組み

対象のチャンネルで送信されたすべてのメッセージは、設定した自動応答と照合されます。一致するものが見つかると、Botはきっかけになったメッセージに直接返信します。各自動応答にはチャンネルごとのクールダウンがあり、Botが同じ返信を何度も繰り返さないようになっています。

照合は2段階で行われます。

1. **正規表現による照合**：パターンは優先度の順に評価されます。最初に一致したパターンがすぐに発動し、それ以降のパターンは確認されません。
2. **AIによる照合**：どの正規表現パターンにも一致せず、AIを使う自動応答が設定されている場合は、それらの候補がすべて1回の呼び出しでAI分類器に送られます。分類器は、あなたが普通の言葉で書いた説明をもとに最も合うものを選び、どの説明にも当てはまらなければ何も返しません。

## 自動応答を作成する

ダッシュボードの <DashboardLink to="moderation/auto-responses">**Moderation > Auto-Responses**</DashboardLink>（モデレーション > 自動応答）を開き、**New Auto-Response**（新しい自動応答）をクリックします。

| 設定 | 説明 |
|---|---|
| **Name**（名前） | この自動応答の内部用ラベル |
| **Trigger type**（トリガーの種類） | **Regex**（パターン一致）または **AI**（普通の言葉による説明） |
| **Pattern**（パターン、正規表現の場合） | メッセージの内容と照合する正規表現。デフォルトでは大文字と小文字を区別しません |
| **Description**（説明、AIの場合） | メッセージが何についてのものであるべきかを普通の言葉で書いた説明。AI分類器が使います |
| **Priority**（優先度） | 正規表現のルールが複数ある場合、数字が小さいものから実行されます |
| **Response type**（返信の種類） | **Text**（プレーンなメッセージでの返信）、または **Embed**（タイトル、説明、色、画像、フッター付きのリッチな埋め込み） |
| **Response content**（返信の内容） | 返信するテキストまたは埋め込みの内容 |
| **Scope**（範囲） | **Global**（すべてのチャンネルで発動）、または **Channel**（選んだチャンネルでのみ発動） |
| **Cooldown**（クールダウン） | 同じチャンネルで同じ返信が再び発動できるようになるまでの時間（秒） |
| **Immune roles**（対象外ロール） | この自動応答を発動させないロール |

## 正規表現のトリガー

正規表現のパターンは、メッセージの内容全体と照合されます。デフォルトでは大文字と小文字を区別しません。パターンをアンカーで固定する必要はありません。`how.*join` というパターンは、「how do I join」「how can I join the server」などのフレーズに一致します。

大文字と小文字を区別したい場合や、その他のフラグが必要な場合は、自動応答でパターンのフラグを設定できます。

## AIのトリガー

AIをトリガーとする自動応答では、パターンの代わりに普通の言葉による説明を使います。たとえば、「サーバーのルールがどこにあるか尋ねているメンバー」という説明のAI自動応答は、毎回まったく違う言い回しであっても、メッセージがルールについて尋ねているとAI分類器が判断したときに発動します。

AIによる分類は、AIを使うすべての自動応答をまとめた1回の呼び出しで行われるため、いくつ設定してもパフォーマンスへの影響は小さく済みます。

<Note>
AI自動応答を使うには、サーバーでAIプラグインを有効にして設定する必要があります。正規表現の自動応答は、それとは関係なく動きます。
</Note>

## チャンネルの範囲

デフォルトでは、新しい自動応答はグローバルで、すべてのチャンネルに適用されます。範囲を **Channel** に設定すると、ルールを適用するチャンネル（またはカテゴリ）を選べます。スレッド内のメッセージは親チャンネルの自動応答とも照合されるため、チャンネル単位のルールはそのチャンネルのスレッドにも適用されます。

## クールダウン

各自動応答には、チャンネルごとのクールダウンがあります。クールダウンの期間内に、Botがあるチャンネルですでにその自動応答で返信していた場合、繰り返しを避けるためにその一致はスキップされます。クールダウンはチャンネルごとに別々にリセットされるため、あるチャンネルで返信しても、別のチャンネルでその自動応答が発動しなくなることはありません。

## 返信の形式

**テキストの返信**：返信はプレーンテキストで送信されます。長い返信は、Discordのメッセージの上限である2000文字に収まるよう、コードブロックや段落の区切りで自動的に分割されます。

**埋め込みの返信**：返信はDiscordのリッチな埋め込みとして送信されます。次の項目を設定できます。

| 項目 | 説明 |
|---|---|
| **Title**（タイトル） | 埋め込みの上部に表示される太字の見出し |
| **Description**（説明） | メインの本文 |
| **Colour**（色） | 左側の枠線の色（16進数のカラーコード） |
| **Image**（画像） | 本文の下に表示される横幅いっぱいの画像 |
| **Thumbnail**（サムネイル） | 右上に表示される小さな画像 |
| **Footer**（フッター） | 埋め込みの下部に表示される小さなテキスト |
