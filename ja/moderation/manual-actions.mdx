Heimdallには、標準的なモデレーション処分すべてに対応するスラッシュコマンドがあります。どの処分も違反記録を作成し、可能な場合は対象のメンバーにDMで通知します。

## 警告

```
/warn <user> <reason> [points] [expiry] [silent]
```

メンバーに警告を出します。警告は違反として記録され、任意でポイントを付けられます。ポイントを指定しなかった場合のデフォルトは1です。

| オプション | 必須 | 説明 |
|---|---|---|
| `user` | はい | 警告するメンバー |
| `reason` | はい | 警告の理由（メンバーに表示されます） |
| `points` | いいえ | この警告のデフォルトのポイントを上書きする |
| `expiry` | いいえ | この違反のポイントが失効するまでの期間（例：`7d`、`30d`） |
| `silent` | いいえ | 指定すると、メンバーにDMで通知しません |

警告されたメンバーには、サーバー名、理由、付与されたポイントを含むDMが届きます。

## BAN

```
/ban <user> <reason> [delete_days] [duration] [silent]
```

メンバーをサーバーからBANします。すでにサーバーから退出したメンバーにも使えます。

| オプション | 必須 | 説明 |
|---|---|---|
| `user` | はい | BANするメンバー、またはユーザーID |
| `reason` | はい | BANの理由 |
| `delete_days` | いいえ | 何日分のメッセージ履歴を削除するか（0〜7） |
| `duration` | いいえ | 一時的なBANの場合、自動でBANが解除されるまでの期間（例：`7d`） |
| `silent` | いいえ | 指定すると、BANの前にメンバーにDMで通知しません |

## BAN解除

```
/unban <user> [reason]
```

ユーザーのBANを解除します。

## キック

```
/kick <user> <reason> [silent]
```

メンバーをサーバーから追い出します。招待リンクがあれば再参加できます。キックは違反として記録されます。

## ミュート

```
/mute <user> <duration> <reason> [silent]
```

メンバーにDiscordのタイムアウトを適用し、指定した期間、メッセージの送信とボイスチャンネルへの参加をできなくします。

| オプション | 必須 | 説明 |
|---|---|---|
| `user` | はい | ミュートするメンバー |
| `duration` | はい | ミュートの期間（例：`1h`、`12h`、`7d`）。最大28日です。 |
| `reason` | はい | ミュートの理由 |
| `silent` | いいえ | 指定すると、メンバーにDMで通知しません |

## 一括削除

```
/purge count <count> [user]
/purge time <duration> [user]
```

現在のチャンネルのメッセージを一括で削除します。2つのモードがあります。

- **count**：最新の `count` 件のメッセージを削除します（最大100件）。
- **time**：直近の `duration`（例：`1h`）に送られたメッセージをすべて削除します。

オプションの `user` フィルターを使うと、特定のメンバーのメッセージだけを削除できます。Discordの制限により、一括削除できるのは送信から14日以内のメッセージだけです。

## 違反の通知DM

Heimdallがメンバーを処分すると、処分の内容、処分が行われたサーバー、理由を説明するDMを送ろうとします。メンバーがDMを無効にしている場合、Botは何も言わずに通知を省略します。`silent` フラグを使うと、どのような場合でもDMは送られません。

## 必要な権限

| コマンド | 権限キー |
|---|---|
| `/warn` | `moderation.enforcement.warn` |
| `/ban`、`/unban` | `moderation.enforcement.ban` |
| `/kick` | `moderation.enforcement.kick` |
| `/mute` | `moderation.enforcement.mute` |
| `/purge` | `moderation.enforcement.purge` |
