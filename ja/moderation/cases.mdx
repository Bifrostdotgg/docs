サーバーでのすべてのBAN、ミュート、キック、警告、チャンネルBAN、そしてMinecraftサーバーでのすべての処分と違反は、`#1482` のような番号付きの **ケース** になります。ケースには、何が起きたか、誰が行ったか、その理由、そしてその後に起きたすべてのこと（BAN解除、異議申し立て、スタッフが追加したメモや添付した証拠）が残ります。メンバーのDiscordでのケースと、連携されたMinecraftアカウントでのケースは、1つのページにまとめて表示されます。

ケースは記録であり、新しい処分の方法ではありません。BANはこれまでどおり `/ban`、`/mc-punish`、またはゲーム内で行います。各ケースは、それが記録している操作にリンクしています。

## ケースになるもの

- Heimdallを通じて、スタッフまたはautomodが行ったBAN、キック、ミュート、警告、チャンネルBAN。
- Discord自体のメニューや別のBotで行われたBAN、キック、タイムアウト。これらは実行した人の記録として残ります。Heimdallはそれを監査ログから読み取るため、Botには **監査ログを表示**（View Audit Log）権限が必要です。
- ダッシュボード、`/mc-punish`、またはゲーム内で行われたMinecraftのBAN、IP BAN、ミュート、警告、キック、そしてMinecraftのすべての違反。

BAN解除、ミュート解除、取り消しは新しいケースにはなりません。解除の対象となったケースが終了し、そのケースは取り消し済みと表示されます。期間を満了したBANは期限切れ、新しいBANに置き換えられたBANは置き換え済みと表示されます。

ケース番号はモデレーションログに表示されるので、スタッフはログの行にある `Case #1482` で検索します。

## ケースを探す

### ダッシュボードで

<DashboardLink to="cases/list">**Cases \> All cases**</DashboardLink>（ケース > すべてのケース）を開きます。プラットフォーム、操作、ステータス、モデレーターで絞り込んだり、人物を検索したりできます。ケースを開くとそのタイムラインが表示され、人物を開くと、その人がDiscordと、本人と連携していることが確認されたMinecraftアカウントで持つすべてのケースが表示されます。Heimdallが連携を推測することはありません。連携されていないMinecraftアカウントは別人として扱われます。

### Discordで

| コマンド | 動作 |
| --- | --- |
| `/case view` | 番号で1つのケースを表示します。メモや証拠の追加と、解除のボタンが付いています |
| `/case lookup` | DiscordユーザーまたはMinecraftプレイヤーのすべてのケースを表示します |
| `/case note` | ケースにメモを追加します |
| `/case evidence` | ケースにファイルやリンクを添付します |
| `/case reason` | ケースの理由を変更します。以前の理由もケースに残ります |

メンバーを右クリックして **アプリ \> View cases** を選ぶと、`/case lookup` と同じ一覧が表示されます。メッセージを右クリックして **アプリ \> Add to case** を選ぶと、そのメッセージへのリンク付きで、メッセージをメモとしてケースにコピーできます。スタッフがチャンネルで話し合って決めたことは、こうして記録に残ります。

### ゲーム内で

`heimdall.admin` を持つスタッフは、`/hd case note <number> <text>` でメモを追加できます。ゲーム内では、メモを追加できるのはMinecraftのケースだけです。非表示のケースには、`heimdall.punishments.hidden` も持つスタッフしか追加できません。

## ケースを解除する

ケースにある **Unban**（BAN解除）、**Unmute**（ミュート解除）、**Revoke**（取り消し）のボタンは、各プラットフォーム自体のコマンドと同じ経路でケースを解除するため、同じ権限が必要です。DiscordでのBAN解除には `moderation.enforcement.ban`、Minecraftでの取り消しには `minecraft.punishments.revoke` が必要です。警告には解除するものがないため、代わりに取り消しとなり、そのポイントは数えられなくなります。

## 異議申し立て

BANまたはミュートされたメンバーが異議を申し立てると、その異議申し立てはメンバーのケースに紐づけられます。ゲーム内のBAN画面にあるリンクと、BANページの各行にあるリンクにはケースが記載されており、ケースが指定されていない異議申し立ては、そのメンバーの有効なBANまたはミュートと照合されます。異議申し立てが紐づけられるのは、申し立てた本人、または本人に連携されたアカウントについてのケースだけです。そのため、メンバーが自分の異議申し立てを他人のケースに紐づけることはできません。

ケースには異議申し立てとその結果が表示され、<DashboardLink to="appeals/submissions">**Appeals \> Submissions**</DashboardLink>（異議申し立て > 送信内容）の異議申し立てからはそのケースにリンクしています。承認すると、ケースは元のプラットフォーム上で解除されます。DiscordではBAN解除またはミュート解除、Minecraftでは取り消しです。

## 公開BANページ

<DashboardLink to="cases/bans-page">**Cases \> Bans page**</DashboardLink>（ケース > BANページ）では、DiscordとMinecraftのBANとミュートの一覧を、それぞれのケース番号とともにBANサイトで公開できます。誰に何を見せるかは、段階ごとに選べます。

| 段階 | 対象 |
| --- | --- |
| Public（公開） | リンクを知っている全員 |
| Signed in（サインイン済み） | Discordでサインインした全員 |
| Members（メンバー） | あなたのサーバーのメンバー |
| Role tiers（ロール段階） | あなたが選んだロールのいずれかを持つメンバー。最大5段階 |

各段階では、それより上の段階で見られるすべての内容に加えて、その段階にチェックした内容が見られます。そのため、どの段階も公開より少ない内容になることはありません。段階ごとに、MinecraftのBAN、MinecraftのIP BAN、Minecraftのミュート、DiscordのBAN、理由、各項目の実行者、期限切れの項目にチェックを入れられます。非表示の処分は、非表示のケースをもともと見られるサインイン済みのスタッフ以外には、決して一覧に表示されません。

DiscordのBANは、あなたがオンにするまで、すべての段階でオフになっています。また、サーバー外の誰かに表示されることになる場合は、<DashboardLink to="cases/bans-page">**Cases \> Bans page**</DashboardLink> に警告が表示されます。MinecraftのBAN一覧はコミュニティでは当たり前のものですが、BANの理由付きのDiscordアカウントの公開一覧は、実在する人についての個人情報です。

**Reset link**（リンクをリセット）を押すとページに新しいアドレスが割り当てられ、古いアドレスは使えなくなります。

## 注意点

ケース機能ができる前のモデレーション記録は、ケース機能付きでBotが初めて起動したときに自動で取り込まれます。何年分もの履歴があるサーバーでは取り込みに数分かかることがあり、それが終わるまでは、<DashboardLink to="cases/list">**Cases**</DashboardLink> とBANページには、ケース機能の導入以降に行われた操作しか表示されません。古い操作には最初の番号が割り当てられるため、履歴が取り込まれても新しいケースの番号は変わりません。

証拠のファイルを添付するには、サーバーでファイルストレージを設定する必要があります。設定していない場合、リンクは添付できますがファイルは添付できません。Discordの添付ファイルのリンクは期限切れになるため、いつの間にか読み込めなくなる証拠は、ないよりも悪いからです。

## 必要な権限

Minecraftのスタッフは、Discordのモデレーターではないことも多いため、閲覧の権限はプラットフォームごとに分かれています。以前の違反記録タブやMinecraftの処分履歴を閲覧できたスタッフは、新しいキーがなくても同じケースを引き続き閲覧できます。

| 操作 | 権限キー |
| --- | --- |
| Discordのケースの閲覧 | `cases.view_discord` |
| Minecraftのケースの閲覧 | `cases.view_minecraft` |
| 閲覧できるプラットフォームでの非表示のケースの表示 | `cases.view_hidden` |
| メモの追加 | `cases.comment` |
| 証拠の追加と削除 | `cases.manage_evidence` |
| ケースの理由の変更 | `cases.edit_reason` |
| 関連するケースの紐づけと、誰のメモでも削除 | `cases.manage` |
| 公開BANページの管理 | `cases.manage_bans_page` |
