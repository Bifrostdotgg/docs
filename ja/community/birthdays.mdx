メンバーが自分の誕生日を登録すると、当日にBotがお祝いのメッセージを投稿し、期間限定のロールを付与することもできます。メンバーが自分で登録するので、日付を集めて回る必要はありません。

## 設定する

ダッシュボードの <DashboardLink to="birthdays/config">**Birthdays**</DashboardLink>（誕生日）を開きます。

| 設定 | 説明 |
| --- | --- |
| **Announcement channel**（お知らせチャンネル） | 誕生日メッセージを投稿するチャンネル |
| **Timezone**（タイムゾーン） | 「今日」がいつ始まるかを決めるタイムゾーン |
| **Announcement hour**（お知らせの時刻） | お知らせを送る時刻（時単位） |
| **Ping role**（通知ロール） | お知らせと一緒にメンションするロール（任意） |
| **Announcement message**（お知らせメッセージ） | メンションには `{mention}`、メンションなしの名前には `{user}` を使えます |
| **Birthday role**（誕生日ロール） | 当日に付与するロール（任意）。付与する時間を時間単位で設定できます |

## メンバーの登録方法

方法は2つあり、どちらも同じ記録に書き込まれます。

- 日と月を指定して `/birthday set` を実行する
- **オープナー**：チャンネルに投稿する、ボタン付きのメッセージです。スラッシュコマンドを使わないメンバーでも、ボタンならクリックしてくれます。

`/birthday remove` で自分の登録を削除します。`/birthday view` は1人のメンバーの誕生日を、`/birthday list` は近づいている誕生日を表示します。

保存されるのは日と月だけです。メンバーに年は尋ねないので、年齢は記録されません。

## 誕生日リスト

ダッシュボードの <DashboardLink to="birthdays/entries">**Birthday List**</DashboardLink>（誕生日リスト）タブには、登録されたすべての誕生日が、近いものから順に表示されます。検索したり、メンバーに代わって登録を追加、編集、削除したりできます。

並び順は暦の日付順ではなく、次のお祝いが近い順です。そのため、12月の誕生日が1年のうち11か月間ずっと一番下にある、ということはありません。

2月29日の誕生日は、その日がない年には2月28日にお祝いされます。3年間スキップされることはありません。

## 必要な権限

| 操作 | 権限キー |
| --- | --- |
| 設定の閲覧 | `birthdays.config.view_config` |
| 設定とオープナーの変更 | `birthdays.config.manage_config` |
| 誕生日リストの閲覧 | `birthdays.entries.view_entries` |
| 他のメンバーの登録の変更 | `birthdays.entries.manage_entries` |

自分の誕生日の登録に権限は必要ありません。どちらの設定キーでもリストを閲覧できるため、すでに誕生日を管理しているスタッフは、リストを見るために別の権限を付与してもらう必要はありません。
