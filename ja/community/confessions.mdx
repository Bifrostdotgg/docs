メンバーが告白を送信すると、Botが番号を付け、投稿者名なしで投稿します。告白は他のメンバーに対しては匿名です。ただし、適切な権限を持つスタッフに対しては匿名ではありません。誤解が生じないよう、この制限は送信パネルでメンバーに明示されています。

## 設定する

ダッシュボードの <DashboardLink to="confessions/config">**Confessions**</DashboardLink>（匿名告白）を開きます。

| 設定 | 説明 |
| --- | --- |
| **Enable confessions**（匿名告白を有効にする） | サーバーに `/confess` を追加します。オフの間はコマンドが削除され、パネルのボタンは受け付けを断ります。 |
| **Confessions channel**（告白チャンネル） | 告白を投稿するチャンネル。そのチャンネルを読める人は誰でも告白を読めます。 |
| **Shortest and longest**（最短と最長） | 文字数の制限で、メンバーの入力中に適用されます。空白や見えない文字は数に含まれないため、最低文字数に届くように水増しすることはできません。 |
| **Cooldown**（クールダウン） | メンバーが次の告白を送るまでに待つ時間。短すぎる、または長すぎるという理由で受け付けられなかった送信では、待ち時間は消費されません。 |

## 送信パネル

パネルを投稿すると、メンバーに **Submit a confession!**（告白を送信）ボタンが表示されるので、メンバーはコマンドを知らなくても使えます。同じチャンネルにもう一度投稿すると、2つ目を追加するのではなく、そのメッセージが更新されます。別のチャンネルに投稿するとそこにコピーが追加され、パネルを投稿するときにすべてのコピーが一覧表示されます（[複数のチャンネルに投稿されたパネル](/ja/dashboard#panels-posted-in-more-than-one-channel) を参照）。どちらの方法でも同じ入力ボックスが開き、動作もまったく同じです。

## 誰が告白を書いたかを見られる人

他のメンバーには決してわかりません。名前もアバターも表示されず、投稿されたメッセージには投稿者につながるものは何もありません。

スタッフの場合は話が別です。`confessions.log.view_author` を持つ人は、<DashboardLink to="confessions/log">**Confessions \> Confession Log**</DashboardLink>（匿名告白 > 告白ログ）で誰が告白を送信したかを調べられます。Botはすべての照会を記録します。これは意図的な設計です。サーバーに追跡不可能な方法で投稿できるなら、それは嫌がらせの手段になり、機能をオフにする以外に対処法がありません。また、誰かをブロックするには、それが誰なのかを知る必要があります。

**Forget who wrote a confession after (days)**（指定日数後に投稿者を忘れる）で、それが可能な期間を決めます。0のままにすると、情報は無期限に保持されます。それ以外の数値を指定すると、告白がその日数を過ぎた時点でBotは投稿者を忘れます。告白自体は残りますが、それ以降はあなたを含め、誰も投稿者を知ることはできなくなります。

## 悪用への対処

| ツール | 動作 |
| --- | --- |
| **Blocklist**（ブロックリスト） | ブロックされたメンバーには、告白が何も言わずに消えるのではなく、送信できないことがはっきり伝えられます。そのため、理由がわからないまま何度も試し続けることはありません。 |
| **Delete**（削除） | チャンネルからメッセージを削除しますが、テキストはログに残ります。そのテキストが通報の証拠になるためです。 |
| **Length limits**（文字数の制限） | 一言だけの告白も、長すぎる文章も防ぎます。 |

告白内の `@everyone` と `@here` は無効化され、書かれたとおりに表示されますが、誰にも通知されません。書式もエスケープされるため、告白で画面幅いっぱいの見出しを投稿したり、Botの発言に見せかけたリンクを投稿したりすることはできません。

## 必要な権限

| 操作 | 権限キー |
| --- | --- |
| 告白の送信 | `confessions.submit`（デフォルトで全員に付与） |
| 設定の閲覧 | `confessions.config.view_config` |
| 設定とブロックリストの変更 | `confessions.config.manage_config` |
| 告白ログの閲覧 | `confessions.log.view_log` |
| 投稿者の表示 | `confessions.log.view_author` |
| 投稿済みの告白の削除 | `confessions.log.delete_confession` |

設定キーでは、あえてログを閲覧できないようにしています。チャンネルやクールダウンの設定は管理業務ですが、メンバーが何を告白したかを読むのはプライベートな部分です。一方を任せられることと、もう一方を任せられることは同じではありません。
