招待トラッカーは、新しいメンバーがどの招待を使ったかを記録し、その招待を作った人の実績として数え、メンバーごとの累計を保ちます。ウェルカムメッセージで使えるプレースホルダーも追加されます。

## 始める前に

招待の追跡には「サーバー管理」権限が必要です。Discordは、この権限を持つBotにしか招待の使用回数を見せません。そして、誰がどの招待で参加したかを知る方法は、その使用回数しかありません。この権限がない場合、機能は不完全なデータを記録するのではなく自動でオフになり、ダッシュボードには権限の付与を案内するボタンが表示されます。

Botに「サーバー管理」を与えたくない場合は、招待の追跡をオフのままにしておきましょう。ほかの機能には影響しません。

また、追跡が数えるのは、有効にした時点からの参加だけです。Discordは過去に誰が招待を使ったかを教えてくれないため、すでに40回使われているリンクについて、その40人を誰かの実績にすることはできません。同じリンクでのこれからの参加は、通常どおり数えられます。

## 設定方法

ダッシュボードの <DashboardLink to="invites/config">**Invite Tracker**</DashboardLink>（招待トラッカー）を開き、**Track invites**（招待を追跡）をオンにします。これでサーバーに `/invites` も追加されます。任意で **join log channel**（参加ログチャンネル）を設定すると、参加のたびに誰が招待したかを示す1行が投稿されます。

## 合計の計算方法

```
total = joined - fake - left + bonus
```

| 項目 | 意味 |
| --- | --- |
| **joined** | そのメンバーの招待で参加した人 |
| **fake** | 参加した時点で、Discordアカウントが設定した日数より新しかった人 |
| **left** | その後サーバーから退出した人 |
| **bonus** | スタッフが手動で追加または削除した分 |

ほかの招待Botの間でも扱いが分かれるため、それぞれの差し引きはオンとオフを切り替えられます。残った人数で実績が減るべきではないと考えるなら、**people who leave do not count**（退出した人は数えない）をオフにしましょう。

知っておきたい点が2つあります。

- **fakeは参加時に判定され、再判定されることはありません。** 参加時に新しかったメンバーは、ずっとfakeとして数えられます。そうしないと、アカウントが古くなるにつれてすべての合計が少しずつ増えていき、いずれ誰かが、実際には失っていない招待を失ったと責められることになります。
- **再参加は、デフォルトでは二重に数えません。** 同じ招待で退出と再参加を繰り返すのは、2つ目のアカウントがなくても数を水増しできる最も簡単な方法です。再参加も記録されて <DashboardLink to="invites/activity">**Invite Tracker \> Invites and Joins**</DashboardLink>（招待トラッカー > 招待と参加）で確認できますが、数には加算されません。

## コマンド

| コマンド | 使える人 |
| --- | --- |
| `/invites view` | 誰でも、自分の数を確認できます |
| `/invites view member:` | 「誰でも確認できる」権限が必要です |
| `/invites leaderboard` | 招待数の上位10人。上位100人は <DashboardLink to="invites/leaderboard">**Invite Tracker \> Leaderboard**</DashboardLink>（招待トラッカー > ランキング）で確認できます |
| `/invites create` | スタッフ向け。キャンペーンごとに区別できるよう、ラベル付きの招待を作ります |
| `/invites bonus` | スタッフ向け。招待数を手動で追加または削除します |

返信はすべて、コマンドを実行した本人にだけ表示されます。ランキングに載った人がメンションされることはありません。

## ウェルカムメッセージのプレースホルダー

ウェルカムメッセージに次のプレースホルダーを追加できます。

| プレースホルダー | 表示される内容 |
| --- | --- |
| `{inviter}` | 招待した人の表示名 |
| `{invitermention}` | その人へのメンション |
| `{inviterinvites}` | その人の現在の招待数 |
| `{invitecode}` | 使われた招待コード |

招待した人を特定できない場合、これらは「unknown」と表示され、ウェルカムメッセージはそのまま送信されます。

## Botが判別できない場合

これは起こりうることで、不具合ではありません。どの場合も隠さずに参加ログに表示されます。

| 表示 | 理由 |
| --- | --- |
| Vanity URL, no inviter to credit（バニティURL、実績を付ける招待者なし） | `discord.gg/yourserver` のリンクを使った場合です。 |
| Two invites used at once（2つの招待が同時に使用） | 2人が同じ瞬間に参加した場合です。2つのコードの使用回数が増えましたが、誰がどちらを使ったかはわかりません。 |
| Invite could not be identified（招待を特定できませんでした） | 「Server Discovery」（サーバー発見）からの参加か、Botが再起動した直後だった場合です。 |
| Bot, added through OAuth（OAuthで追加されたBot） | Botは招待されるのではなく、追加されるものです。 |

## 必要な権限

| 操作 | 権限キー |
| --- | --- |
| 自分の数の確認 | `invites.view_own`（デフォルトで全員に付与） |
| 誰の数でも確認する、ランキングの表示 | `invites.view_others`（デフォルトで全員に付与） |
| 設定の表示 | `invites.config.view_config` |
| 設定の変更 | `invites.config.manage_config` |
| ラベル付きの招待の作成 | `invites.manage.create_invite` |
| ボーナス招待の追加と削除 | `invites.manage.manage_bonus` |

ボーナスは、ここで人が自由に作り出せる唯一の数字です。そのため専用のキーがあり、調整のたびに誰がなぜ行ったかが記録されます。
