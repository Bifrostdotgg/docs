目標とは、チャンネルに投稿され、自動で更新される進捗バーです。メンバー数の節目、ブーストの目標、メンバー募集キャンペーンなど、数字で表せるものなら何にでも使えます。

## 目標で追跡できるもの

| ソース | 進捗の元になるもの |
| --- | --- |
| **メンバー数** | サーバーのメンバー数 |
| **ブースト** | サーバーの現在のブースト数 |
| **ロールのメンバー** | 選んだロールを持っているメンバーの数 |
| **手動** | `/goal set` で自分で設定する数値 |

最初の3つは自動で更新されます。手動の目標は、集まった寄付金や別サイトでの登録数など、Botからは見えないもののためのもので、`/goal set` で値を動かしたり、`/goal add` で少しずつ増やしたりします。

## 設定方法

ダッシュボードの <DashboardLink to="goals">**Goals**</DashboardLink>（目標）を開き、ソース、目標値、チャンネルを選びます。Botが進捗バーを投稿し、定期的なポーリングで最新の状態に保つので、誰も手を触れなくても正確なまま維持されます。

目標は表示専用なので、メンバー側の権限は必要ありません。誰かが誤って目標を操作してしまうこともありません。

## 必要な権限

| 操作 | 権限キー |
| --- | --- |
| 設定の表示 | `goals.config.view_config` |
| 目標の作成と編集 | `goals.config.manage_config` |

手動の目標を動かすことは目標の編集にあたるため、`/goal set` と `/goal add` にも管理用のキーが必要です。
