これらの汎用コマンドを使うと、メンバーや管理者がBotとDiscordユーザーに関する基本的な運用情報を確認できます。

## Botのレイテンシを確認する

```
/ping
```

BotとDiscordのAPIの間の現在の往復レイテンシを測定します。応答には次の項目が表示されます。

- **API latency**（APIレイテンシ）: BotがDiscordからイベントを受け取るまでの時間
- **Gateway latency**（ゲートウェイレイテンシ）: WebSocketのハートビートの往復時間
- **Database latency**（データベースレイテンシ）: 簡単なデータベースクエリが完了するまでの時間

このコマンドは、Botが応答しているかを確かめたり、遅さの原因がBot、DiscordのAPI、データベースのどれにあるかを切り分けたりするのに役立ちます。

## Botの稼働時間を確認する

```
/uptime
```

前回の再起動からBotが稼働している時間を表示します。読みやすい形式の期間（例：「3 days, 14 hours, 22 minutes」）と、Botが起動した正確な日時が表示されます。

## ユーザー情報を表示する

```
/userinfo [user]
```

指定したメンバーのプロフィールカードを表示します（ユーザーを指定しなかった場合は自分のプロフィール）。カードには次の項目が表示されます。

| 項目 | 説明 |
|---|---|
| **Username** | Discordのユーザー名と表示名 |
| **User ID** | DiscordのスノーフレークID |
| **Account created** | Discordアカウントが登録された日時 |
| **Joined server** | メンバーがこのサーバーに参加した日時 |
| **Roles** | メンバーが現在持っているすべてのロール |
| **Nickname** | 設定されている場合、サーバー固有のニックネーム |
| **Bot** | アカウントがBotかどうか |

`/userinfo` は、Botを含め、表示できるすべてのメンバーに使えます。サーバーから退出したメンバーも、ユーザーIDを指定すれば調べられます。

## 必要な権限

これらのコマンドは、デフォルトですべてのメンバーが使えます。

| コマンド | 権限キー |
|---|---|
| `/ping`, `/uptime`, `/userinfo` | `ping.use`（デフォルトで許可） |
