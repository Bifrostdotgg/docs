Heimdallは、どんな規模のDiscordサーバーでも無料で使え、メンバー数の上限もありません。Freeにはすべてのコアプラグインが含まれていて、コミュニティをまるごと運営できるだけのたっぷりの制限があります。Premiumはそうした制限を解除し、パワー機能を使えるようにします。White-Labelでは、さらにあなた独自のブランドを加えられます。

プランを比較している場合は、[料金ページ](https://bifrost.gg/heimdall/pricing) にすべてのプランを並べた詳しい比較があります。

## Premiumで使えるようになること

Premiumでできることは2つです。Freeのすべての利用上限を引き上げることと、無料では使えない機能をオンにすることです。

## 解除される制限

以下の制限はすべてサーバーごとに適用されます。Freeの値はあえて余裕を持たせてあり、Premiumではそれぞれが引き上げられます。White-LabelはPremiumと同じです。

| 機能 | Free | Premium |
| --- | --- | --- |
| ダッシュボードのスタッフ枠 | 3 | 無制限 |
| チケットパネル | 1 | 25 |
| チケットカテゴリ | 5 | 25 |
| チケットカテゴリごとのフォームの質問 | 5 | 上限まで |
| Automodルール | 5 | 50 |
| 段階的処分の段階 | 3 | 無制限 |
| 自動応答 | 5 | 50 |
| 固定メッセージ | 5 | 25 |
| Modmailカテゴリ | 2 | 25 |
| カテゴリごとのModmailフォームの項目 | 3 | 10 |
| 応募フォーム | 3 | 無制限 |
| 異議申し立てフォーム | 1 | 10 |
| ロールボタンパネル | 5 | 25 |
| スターボード | 1 | 無制限 |
| タグ | 15 | 無制限 |
| 予約中の投稿 | 1 | 無制限 |
| 実施中の投票 | 1 | 50 |
| 提案チャンネル | 1 | 10 |
| コンソールアーカイブの保存期間 | 7日 | 365日 |

## Premium限定の機能

これらはFreeではオフになっていて、Premiumで使えるようになります。

| 機能 | 内容 |
| --- | --- |
| サポートスイート | チケットとModmailでのSLAのスケジュール、スタッフのノルマ、チケットの評価付け、分析、顧客レビュー |
| 添付ファイル形式のフォームの質問 | チケット、応募、Modmailのフォームで、メンバーが回答としてファイルをアップロードできます |
| サブカテゴリごとのログの振り分け | サブカテゴリごとに、ログを別々のチャンネルに送ります |
| 埋め込みのカスタムカラーとフッター | Botの埋め込みを、独自のアクセントカラーとフッターのテキストでブランディングします |
| カスタマーポータル | メンバーが自分のチケットや連携済みアカウントを確認できる、ホスト型のセルフサービスパネル |
| Tebexストア管理 | DiscordからTebexストアのパッケージ、セール、顧客の検索を管理します |
| 投票のCSVエクスポート | 投票の結果をCSVファイルにエクスポートします |
| ホスト型ボイス文字起こし | ボイスチケットや録音を自動で文字起こしします |
| 優先サポート | Bifröstチームから、より早くサポートを受けられます |

## White-Label

White-Labelは最上位のプランです。Premiumのすべての機能を含み、さらにBotをあなたのものにします。

- Botのメッセージや埋め込みから、HeimdallとBifröstのブランド表示をすべて取り除きます
- あなた自身のBotとして、そのBotの名前、アバター、トークンで動きます
- ネットワーク、代理店、ブランドを持つコミュニティ向けに作られています

White-Labelはシート単位のライセンスです。1シートで、White-Label化したサーバー1つをカバーします。3つのサーバーでWhite-LabelのBotを運用するなら3シートで、シートはいつでも追加・削除できます。

<Note>
  White-Labelはあなた自身のBotアプリケーションで動くため、導入にはBotのトークンが必要です。セットアップの手助けが必要な場合は、[サポートサーバー](https://discord.bifrost.gg) でチケットを作成してください。
</Note>

### 特権インテント

HeimdallがあなたのBotアプリケーションを動かすには、事前に2つの特権ゲートウェイインテントをオンにしておく必要があります。[Discord Developer Portal](https://discord.com/developers/applications) でアプリケーションを開き、**Bot** タブの **Privileged Gateway Intents** で次のように設定します。

| インテント | 設定 | 理由 |
| --- | --- | --- |
| Server Members Intent | オン | 権限、モデレーション、ウェルカムメッセージ、自動ロール、ロール同期のすべてに、メンバーとロールのデータが必要です |
| Message Content Intent | オン | チケット、Modmail、automod、メッセージのログ、翻訳のすべてが、メッセージの内容を読み取ります |
| Presence Intent | オフ | Heimdallがプレゼンスを読み取ることはありません |

必要なインテントのどちらかがオフだと、DiscordはBotのログインを拒否し、Botは起動しません。オンにしてから、もう一度導入してください。

ユーザー数が10,000人未満なら、インテントを切り替えるだけで十分です。Botが到達可能なユニークユーザー数が10,000人に達すると、Discordがアプリケーションを所有するアカウントにDMを送り、90日後を期限としてインテントの審査を申請するよう求めます。それまでBotは動き続けますが、期限を過ぎるとDiscordがインテントをオフにします。

<Card title="特権インテントを申請する" icon="shield-check" href="https://bifrost.gg/heimdall/guides/privileged-intents">
  Discordのインテント審査フォームのすべての質問に対する、Botの名前入りのコピー＆ペースト用の回答と、添付するスクリーンショット。
</Card>

### カスタムステータス

White-LabelのBotは、メンバーリストにカスタムステータスを表示でき、複数のステータスを順番に切り替えることもできます。設定するには、ダッシュボードでプロフィールメニューを開き、**Whitelabel Bot** を選んで **Custom status**（カスタムステータス）カードを探します。変更は保存してから数秒で稼働中のBotに反映されます。

- ステータスは最大10個まで追加できます。2つ以上あると、Botは順番に切り替えて表示します。
- 切り替えの間隔は、15秒ごとから1日1回まで選べます。デフォルトは1分ごとです。
- 各ステータスには種類があります：**Playing**（プレイ中）、**Watching**（視聴中）、**Listening to**（再生中）、**Competing in**（参戦中）、**Custom**（カスタム。前に動詞を付けず、テキストだけを表示）。
- 各ステータスは最大128文字です。

2つのプレースホルダーで、リアルタイムの数字を入れられます。

| プレースホルダー | 表示される内容 |
| --- | --- |
| `{servers}` | Botが参加しているサーバーの数 |
| `{members}` | それらのサーバーの合計メンバー数 |

たとえば `Watching over {members} members` は「Watching over 1,234 members」と表示されます。数字は、ステータスが1つだけの場合は約10分ごとに、複数ある場合はBotが切り替えるたびに更新されます。

<Note>
  DiscordはBotがステータスを変更できる頻度を制限しているため、最も速い切り替え間隔は15秒になっています。
</Note>

## 料金

| プラン | 月払い | 年払い |
| --- | --- | --- |
| Premium | £5.99/月 | £57.99/年 |
| White-Label | 1シートあたり£9.99/月 | 1シートあたり£95.99/年 |

年払いは月払いより約20%お得で、価格はすべてVAT込みです。Odin AIは別料金のオプションのアドオンです。料金については [Odin AI](/ja/ai/odin) を参照してください。

<Note>
  一律料金の開始前から契約していますか？既存のプランと料金はそのままです。旧プランはこれまでとまったく同じように使え、移行や再請求は一切ありません。
</Note>

## 制限の適用方法

制限は、設定を作成または編集するときに確認され、Botの稼働中に確認されることはありません。制限にぶつかるのは新しく何かを追加するときだけなので、進行中のチケット、automod、その他すべての機能は、プランに関係なく動き続けます。

有料プランからダウングレードしても、何も削除されません。

<Steps>
  <Step title="請求期間の終了">
    支払い済みの期間が終わるまで、すべての機能を使えます。
  </Step>

  <Step title="14日間の猶予期間">
    その後14日間はすべてが動き続けるので、どうするか決めたり、再契約したりする時間があります。
  </Step>

  <Step title="上限を超えた項目は一時停止">
    Freeの上限を超えた分は、削除されずに無効化されます。デフォルトでは最近の項目が有効なまま残り、どれを残すかを選び直すこともできます。
  </Step>

  <Step title="すぐに復元">
    いつでも再契約すれば、一時停止していた項目はすべて元どおりにオンに戻ります。
  </Step>
</Steps>

モデレーション、automod、異議申し立てなどの安全機能には、猶予期間の延長と段階的な警告が先にあるため、サーバーが無防備になることはありません。

  <Step title="ダッシュボードを開く">

  </Step>

  <Step title="Billingを開く">
    **Billing**（請求）エリアを開き、**Premium** または **White-Label** を、月払いか年払いで選びます。
  </Step>

  <Step title="購入手続きを完了する">
    購入手続きを終えると、新しい上限と機能がすぐに使えるようになります。Botを招待し直す必要はありません。
  </Step>
</Steps>
