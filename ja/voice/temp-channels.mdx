一時ボイスチャンネルの仕組みを使うと、メンバーが必要なときに自分のボイスチャンネルを作れます。あなたは「作成用」のボイスチャンネルを1つ以上指定します。メンバーが作成用チャンネルに参加すると、Botはすぐに新しいボイスチャンネルを作ってメンバーをそこへ移動させ、最後のメンバーが退出するとチャンネルを自動で削除します。

これにより、管理者が少人数のグループのためにボイスチャンネルを手動で作ったり削除したりする必要がなくなり、メンバーに「チャンネルの管理」権限を与えなくても、自分たちの場所を自分で管理できるようになります。

## メンバー側の使い方

作成用のボイスチャンネル（たいてい「Create a channel」や「Join to create」のような名前です）に参加します。Botがデフォルトであなたの名前を付けた新しいチャンネルを作り、あなたをそこへ移動させます。あとはほかの人を招待できます。全員が退出すると、Botがチャンネルを削除します。

一時チャンネルにいる間は、`/tempvc` コマンドでそのチャンネルを管理できます。

## 設定方法

ダッシュボードの <DashboardLink to="tempvc/config">**Temp VC \> Configuration**</DashboardLink>（一時VC > 設定）を開きます。

| 設定 | 説明 |
| --- | --- |
| **Creator channel**（作成用チャンネル） | チャンネル作成のきっかけとしてメンバーが参加するボイスチャンネル |
| **Category**（カテゴリ） | 新しい一時チャンネルが作られるカテゴリ |
| **Default name**（デフォルトの名前） | 新しいチャンネル名のテンプレート。`{user}` と `{count}` の変数が使えます。 |
| **Default user limit**（デフォルトの人数制限） | 新しいチャンネルに参加できるメンバーの数（0 = 無制限） |
| **Default bitrate**（デフォルトのビットレート） | 新しいチャンネルの音質 |
| **Permitted roles**（許可するロール） | 作成用チャンネルを使えるロール（空欄にすると全メンバー） |

設定の異なる作成用チャンネルを複数用意できます。

## メンバー向けの操作

```text
/tempvc create
/tempvc delete
/tempvc delete-all
```

| サブコマンド | 説明 |
| --- | --- |
| `create` | 一時チャンネルを手動で作る（作成用チャンネルに参加せずに） |
| `delete` | 現在の一時チャンネルをすぐに削除する |
| `delete-all` | 自分が所有する一時チャンネルをすべて削除する |

Botが適切な権限を与えていれば、メンバーはDiscordのボイスチャンネルのコンテキストメニューから、一時チャンネルの名前の変更、人数制限の設定、ロックもできます。

## 有効なチャンネルを確認する

ダッシュボードの <DashboardLink to="tempvc/active">**Temp VC \> Active Channels**</DashboardLink>（一時VC > 有効なチャンネル）を開くと、現在有効な一時チャンネルをすべて確認できます。誰が作ったか、何人のメンバーがいるか、どれくらいの時間使われているかが表示されます。

## 必要な権限

| 操作 | 権限キー |
| --- | --- |
| 作成用チャンネルの使用 | デフォルトで全メンバーが利用可能 |
| 設定の表示 | `tempvc.view_config` |
| 設定の変更 | `tempvc.manage_config` |
| チャンネルの管理（強制削除など） | `tempvc.manage_channels` |
