Heimdallには、インタラクティブなボタン操作でDiscord内だけで遊べるボードゲームが6種類あります。ゲームの種類に応じて、1人用または2人用のモードに対応しています。

## 遊べるゲーム

### 2048

```
/2048
```

おなじみの数字スライドパズルです。数字のタイルが並んだ4x4のグリッドで、タイルを一方向にスライドさせると同じ数字同士が合体します。2048のタイルを作れば勝ちです。方向ボタンだけで遊べます。1人用です。

### 四目並べ（Connect Four）

```
/connect4 [opponent]
```

7列6段のグリッドに色付きのディスクを落としていきます。縦、横、斜めのいずれかで先に4つ並べた人の勝ちです。Botとの1人対戦にも、2人対戦にも対応しています。

### 神経衰弱（Memory）

```
/memory
```

カードを揃えるゲームです。盤面には裏向きのカードが並んでいます。2枚ずつめくってペアを揃えましょう。できるだけ少ない回数ですべてのペアを見つけてください。1人用です。

### 三目並べ（Tic-Tac-Toe）

```
/tictactoe [opponent]
```

3x3のグリッドで3つ並べる定番ゲームです。Botとの1人対戦にも、2人対戦にも対応しています。

### バトルシップ

```
/battleship [opponent]
```

海戦の戦略ゲームです。10x10のグリッドに自分の艦隊を配置し、相手より先に相手の艦隊を沈めることを目指します。2人対戦にも、Botとの1人対戦にも対応しています。

### ソリティア

```
/solitaire
```

標準的なクロンダイク・ソリティアです。カードをスートごとに、エースからキングまで昇順で組札の山に並べます。1人用です。

## 2人用のゲーム

対戦相手がいるゲームでは、`opponent` オプションで相手のメンバーを指定します。

```
/connect4 opponent:@Username
```

相手には招待が届き、承認するとゲームが始まります。相手が60秒以内に応答しなかった場合、招待は期限切れになります。

## ゲームのタイムアウト

一定時間（ゲームによって異なりますが、通常は5〜10分）手が打たれないと、進行中のゲームは期限切れになります。Botが、操作がなかったためゲームが終了したことを知らせるメッセージを投稿します。

## 必要な権限

| 操作 | 権限キー |
|---|---|
| ボードゲームで遊ぶ | `games.use`（デフォルトで許可） |
