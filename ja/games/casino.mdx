カジノゲームは、サーバーの仮想経済を使って遊ぶ賭けのゲームです。ラウンドごとにコインを賭け、勝てばゲームのオッズに応じて配当があり、負けると残高が減ります。実際のお金は一切関係ありません。

<Warning>
カジノゲームを遊ぶには、エコノミーシステムが設定されている必要があります。賭けるにはメンバーがコインの残高を持っている必要があります。設定方法は[エコノミー](/ja/games/economy)のページをご覧ください。
</Warning>

## 遊べるゲーム

### ブラックジャック

```
/blackjack <bet>
```

ディーラーと対戦する標準的なブラックジャックです。21を超えずに、ディーラーより21に近づけましょう。状況に応じてヒット、スタンド、ダブル、スプリットが使えます。ブラックジャック（最初の配札でエースと10の札）の配当は3:2です。

### コイントス

```
/coinflip <bet> <heads|tails>
```

表か裏かを宣言します。当たれば配当は1:1です。

### ダイス

```
/dice <bet> <target>
```

サイコロを2つ振り、出目の合計が目標値より大きいか小さいか、またはちょうど目標値になるかを予想します。配当はその結果になる確率に応じて変わります。

### ハイ＆ロー

```
/higher-lower <bet>
```

カードが1枚めくられます。次のカードがそれより高いか低いかを予想します。連続で当てるほど賞金が倍増していきます。いつでも精算して、それまでに貯まった配当を受け取れます。

### 競馬

```
/horse-racing <bet> <horse>
```

シミュレーションのレースで、何頭かいる馬のうち1頭に賭けます。馬ごとにオッズが異なります。レースは数ラウンドにわたって進み、順位の変化がメッセージに投稿されます。

### マインズ

```
/mines <bet> <mine_count>
```

タイルのグリッドに、決まった数の地雷が隠されています。タイルを開けるたびに倍率が上がるので、地雷を踏む前に精算しましょう。地雷が多いほどリスクが高く、得られる可能性のある報酬も大きくなります。

### ルーレット

```
/roulette <bet> <type>
```

数字、色（赤/黒）、または範囲（奇数/偶数、1〜18、19〜36）に賭けます。仮想のホイールが回り、配当は標準的なルーレットのオッズに従います。1つの数字への賭けは35:1、色への賭けは1:1です。

## 賭け金の上限

ゲームごとの最小と最大の賭け金は、<DashboardLink to="games/config/economy">**Games > Configuration > Economy**</DashboardLink>（ゲーム > 設定 > エコノミー）で設定します。メンバーは現在の残高を超えて賭けることはできません。

## 必要な権限

| 操作 | 権限キー |
|---|---|
| カジノゲームを遊ぶ | `games.use`（デフォルトで許可） |
