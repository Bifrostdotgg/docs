Webサイトを運営していて、ログに **HeimdallBot** を見つけた方のためのページです。

```
Mozilla/5.0 (compatible; HeimdallBot/2.0; +https://heimdall.gg/docs/crawler)
```

HeimdallはDiscordのBotです。独自ブランドのコピーを運用しているサーバーも含め、すべてのHeimdallインスタンスが同じユーザーエージェントを送信するため、1つのルールですべてに対応できます。

## アクセスする理由

HeimdallBotがページを取得するのは、Discordサーバーの管理者がそのページを指定したときだけです。コンテンツを探してWebを巡回することはありません。

- **ナレッジベースの取り込み。** サーバー管理者が、HeimdallのAIアシスタントである[Odin](/ja/ai/odin)がメンバーの質問に答えられるように、ページを取り込んだりサイトを深くクロールしたりします。たいていは管理者自身のドキュメント、Wiki、ヘルプセンターです。
- **毎週の再確認。** そうして取り込まれた各ページは、コピーを最新に保つため、おおよそ週に1回確認されます。確認では `If-None-Match` と `If-Modified-Since` を送るため、ページに変更がなければ、通常は本文のない `304` が1回返るだけで済みます。
- **監視対象のサイト。** 管理者は、取り込んだサイトに新しいページが追加されていないか監視するよう依頼できます。監視対象のサイトはおおよそ週に1回再クロールされ、最大100ページを訪問し、1回につき追加される新しいページは最大25ページです。
- **リンクの確認。** [添付ファイルブロッカー](/ja/utilities/attachment-blocker)を使っているサーバーで誰かがリンクを投稿すると、HeimdallはそれがGIFか動画かを判断するために、その1ページを確認することがあります。読み取るのは最大で先頭の256 KBまでで、結果は最大1日間記憶されます。

## 動作

- **robots.txtに従います**（[RFC 9309](https://www.rfc-editor.org/rfc/rfc9309)）。リダイレクトを含め、ナレッジベースのすべての取得で従います。`HeimdallBot` のグループがあればそれが適用され、なければ `*` のグループが適用されます。
  - robots.txtが4xxを返した場合は、robots.txtがないものとして扱い、すべてのページを取得できるものとします。例外は `429 Too Many Requests` で、この場合HeimdallBotはその回はあなたのサイトから何も取得しません。
  - 5xxを返した場合やタイムアウトした場合は、HeimdallBotはもう一度だけ試し、それでもだめならその回はあなたのサイトから何も取得しません。
- **リクエストの間隔を空けます。** クロール、取り込み、毎週の確認のそれぞれで、1つのサイトに送るリクエストは最大で毎秒2回です。robots.txtで `Crawl-delay` が設定されていれば、それより少なくなります。2つが同時に実行される場合（たとえば2つのDiscordサーバーが同時にあなたのサイトを取り込む場合）は、それぞれ別々にペースが調整されます。10秒を超える遅延は10秒として扱われます。
- **クロール中は `noindex` と `nofollow` に従います。** 対象は `<meta name="robots">`、`<meta name="HeimdallBot">`、`X-Robots-Tag` ヘッダーです。`rel="nofollow"`、`ugc`、`sponsored` が付いたリンクは決してたどりません。
- **深いクロールも小規模にとどまります。** 1つのサイトから出ず、訪問するのは最大100ページで、5分経つと停止します。
- **Markdown版を求めることがあります。** Mintlify、GitBook、DocusaurusのようにMarkdown版を提供しているドキュメントサイトでは、まずページの `.md` 版を求めます。通常はHTMLより小さくなります。
- **JavaScriptは実行せず、ログインもしません。**

添付ファイルブロッカーのリンク確認はrobots.txtを読みません。リンクのプレビューと同じく、人がページを共有したからこそ取得するものです。止めたい場合は、ユーザーエージェントをブロックしてください。

## ブロックまたは制限する

サイト全体でHeimdallBotを拒否するには、robots.txtに次の内容を追加します。

```
User-agent: HeimdallBot
Disallow: /
```

サイトの一部だけを拒否する、または速度を落とすには、次のようにします。

```
User-agent: HeimdallBot
Disallow: /private/
Crawl-delay: 5
```

robots.txtは、1つのジョブ（1回のクロール、1回分の取り込み、1回の毎週の確認）につき1回読み込まれます。新しいクロールは変更にすぐ従い、毎週の確認は1週間以内に従います。すでに取り込まれたページはそのサーバーのナレッジベースに残りますが、あなたのサイトから更新されることはなくなります。

サーバーやファイアウォールで `HeimdallBot` に一致させて、ユーザーエージェントをブロックすることもできます。
