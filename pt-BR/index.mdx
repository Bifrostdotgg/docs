O Heimdall é um bot de Discord da Bifröst construído em torno de um sistema de plugins. Cada recurso é um plugin que pode ser ativado ou desativado de forma independente. A configuração é feita pelo painel web em [bot.bifrost.gg](https://bot.bifrost.gg), onde os administradores do servidor controlam tudo, das regras de moderação às categorias de ticket e às configurações da economia dos jogos.

Esta documentação cobre todos os recursos disponíveis tanto para administradores de servidor quanto para membros comuns. Se você está avaliando o Heimdall, veja a [página de preços](https://bifrost.gg/heimdall/pricing) para comparar os planos disponíveis.
