description: "La documentación completa de Heimdall, un bot de Discord basado en plugins y una plataforma de gestión de comunidades."
---

Heimdall es un bot de Discord de Bifröst construido alrededor de un sistema de plugins. Cada función es un plugin que se puede activar o desactivar por separado. La configuración se hace desde el panel web en [bot.bifrost.gg](https://bot.bifrost.gg), donde los administradores del servidor lo controlan todo, desde las reglas de moderación hasta las categorías de tickets o los ajustes de la economía de los juegos.

Esta documentación cubre todas las funciones disponibles, tanto para los administradores del servidor como para los miembros normales. Si estás valorando Heimdall, consulta la [página de precios](https://bifrost.gg/heimdall/pricing) para comparar los planes disponibles.
