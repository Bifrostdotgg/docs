title: "Documentation de Heimdall"
description: "La documentation complète de Heimdall, un bot Discord à plugins et une plateforme de gestion de communauté."
---

Heimdall est un bot Discord de Bifröst construit autour d’un système de plugins. Chaque fonctionnalité est un plugin qui peut être activé ou désactivé indépendamment. La configuration se fait sur le tableau de bord web à l’adresse [bot.bifrost.gg](https://bot.bifrost.gg), où les administrateurs de serveur contrôlent tout, des règles de modération aux catégories de tickets en passant par les réglages de l’économie des jeux.

Cette documentation couvre toutes les fonctionnalités disponibles pour les administrateurs de serveur comme pour les membres. Si tu évalues Heimdall, consulte la [page des tarifs](https://bifrost.gg/heimdall/pricing) pour comparer les offres disponibles.
